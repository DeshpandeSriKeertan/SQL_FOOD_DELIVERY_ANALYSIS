# Food Delivery Analysis Using SQL

## Project Overview

The **Food Delivery Analysis** project is a SQL-based data analysis project that explores food delivery business data using MySQL.

The project focuses on analysing customer behaviour, restaurant performance, order trends, menu item popularity, customer ratings, and delivery partner performance.

A relational database named `food_delivery` is designed with eight interconnected tables. SQL queries, views, stored procedures, and functions are used to retrieve and analyse data and answer practical business questions.

## Project Objectives

- Analyse customer ordering behaviour and spending patterns.
- Identify restaurants generating higher revenue.
- Find popular menu items based on order activity.
- Analyse order trends over time.
- Evaluate restaurant ratings and customer feedback.
- Examine delivery partner performance.
- Practise SQL concepts through real-world business scenarios.

## Database Schema

The project uses eight relational tables:

| Table | Description |
|---|---|
| `customers` | Stores customer-related information. |
| `restaurants` | Stores restaurant-related information. |
| `menu_items` | Contains menu items associated with restaurants. |
| `delivery_partners` | Stores delivery partner information. |
| `orders` | Contains customer order records and related references. |
| `order_items` | Stores the items associated with individual orders. |
| `payments` | Contains payment information associated with orders. |
| `reviews` | Stores customer reviews associated with orders. |

### Key Relationships

The database uses primary keys and foreign keys to maintain relationships between tables.

- **Customers → Orders:** One customer can place multiple orders.
- **Restaurants → Menu Items:** One restaurant can have multiple menu items.
- **Restaurants → Orders:** One restaurant can receive multiple orders.
- **Delivery Partners → Orders:** One delivery partner can handle multiple orders.
- **Orders → Order Items:** One order can contain multiple order items.
- **Menu Items → Order Items:** One menu item can appear in multiple order items.
- **Orders → Payments:** Each order is associated with a payment record in the sample database design.
- **Orders → Reviews:** An order can have an associated customer review.
- **Customers → Reviews:** One customer can submit multiple reviews.

The database design uses relational keys to connect the tables and support analysis across different business areas.

## How to Run the Project

### Prerequisites

- Install MySQL Server 8.0 or above.
- Install MySQL Workbench.
- Ensure the MySQL server is running.

### Step 1: Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/https://github.com/DeshpandeSriKeertan/Food-Delivery-Analysis.git
```

Replace `YOUR_USERNAME` with your GitHub username.

### Step 2: Open MySQL Workbench

1. Open MySQL Workbench.
2. Connect to your local MySQL server.
3. Open the SQL scripts from the `database` folder.

### Step 3: Create Database and Tables

Open and execute:

```text
01_create_tables.sql
```

This creates the database and its tables.

### Step 4: Insert Sample Data

Execute:

```text
02_insert_tables.sql
```

This populates the database with sample records.

### Step 5: Execute Analysis Queries

Open:

```text
03_queries.sql
```

Run the queries to explore customer spending, restaurant revenue, popular menu items, ratings, order trends, and delivery partner performance.

### Step 6: Create Views

Execute:

```text
04_views.sql
```

This creates reusable views for accessing summarised information.

### Step 7: Execute Stored Procedures and Functions

Run:

```text
05_procedures.sql
06_functions.sql
```

These scripts create reusable stored procedures and functions.

**Note:** Execute the scripts in the order described above so that the required database objects exist before they are used.
